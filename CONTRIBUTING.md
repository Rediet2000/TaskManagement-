# Contributing to TaskMaster Pro

First off, thank you for considering contributing to TaskMaster Pro! It's people like you that make TaskMaster Pro such a great tool.

## How Can I Contribute?

### Reporting Bugs
- Use the GitHub issue tracker to report bugs.
- Describe the bug and steps to reproduce it.

### Suggesting Enhancements
- Open a GitHub issue with the "feature request" label.
- Explain why the feature would be useful.

### Pull Requests
1. Fork the repository.
2. Create a new branch: `git checkout -b feature-name`.
3. Make your changes and commit them: `git commit -m 'Add some feature'`.
4. Push to the branch: `git push origin feature-name`.
5. Submit a pull request.

## Coding Standards
- Follow PEP 8 for Python.
- Follow Angular style guide for frontend.
- Ensure all new features include appropriate tests.

## Security
If you find a security vulnerability, please do NOT open an issue. Instead, email security@taskmasterpro.com instead.

Thank you!
